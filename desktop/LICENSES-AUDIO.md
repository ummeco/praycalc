# Audio Asset Licenses — PrayCalc Desktop

Documents the provenance/permission status of the adhan (call to prayer)
recordings bundled with the desktop app, per the licensing-honesty
requirement in ASI Policy 4 (never fabricate a license or rights claim).

## Bundled recordings

| File | Location | Recitation | License / permission status |
|---|---|---|---|
| `public/adhan/makkah.mp3` | `desktop/public/adhan/makkah.mp3` | "Makkah"-style adhan | **Provenance unverified** — replace before store distribution |
| `public/adhan/mishari.mp3` | `desktop/public/adhan/mishari.mp3` | "Mishari" adhan | **Provenance unverified** — replace before store distribution |

## What "provenance unverified" means

Neither file's original source, reciter attribution, or usage rights have
been confirmed against a documented, re-checkable source (e.g. a named
public-domain release, an explicit Creative Commons grant, or a written
permission from the reciter/rights holder). No license is claimed here
because none has been verified — this notice exists so the gap is visible
rather than silently assumed away.

## Required before any app-store submission (Apple App Store, Microsoft
Store, Linux package repositories with content-licensing review, etc.)

1. Identify the actual source/reciter for each file.
2. Obtain and archive written permission, or replace the file with audio
   that has a clear, verifiable license (public domain, CC-licensed with
   attribution satisfied, or a paid/licensed recording).
3. Update the table above with the confirmed source and license once
   verified — do not mark a row "licensed" without a checkable citation.

## Scope

This file covers only the desktop app's bundled audio
(`desktop/public/adhan/*.mp3`). It does not speak to audio assets used by
other PrayCalc surfaces (web, mobile, TV) — each surface's own audio, if
any, needs its own equivalent audit.
